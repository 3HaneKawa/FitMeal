# 用户访谈指南

## 访谈对象

建议访谈 5-10 人，筛选标准：

1. 每周健身 2 次以上
2. 有减脂或增肌目标
3. 每周至少自己做 2 顿饭
4. 有外食或点外卖经历
5. 对热量、蛋白质、脂肪有基本认知

## 访谈问题

### 背景问题

1. 你现在的健身目标是什么？
2. 你一周做几顿饭？通常什么时候做？
3. 你最常准备哪些食材？
4. 最常外食的菜品类型有哪些？

### 决策问题

5. 你如何决定今晚吃什么？
6. 上一周有没有纠结过吃什么？当时怎么解决？
7. 你会使用哪些工具？为什么不持续用？
8. 你最在意热量、蛋白、口感、时间，还是食材浪费？

### 场景问题

9. 训练后你通常怎么吃？
10. 减脂期外食时你如何选择？
11. 如果只剩 2-3 种食材，你希望系统怎么做？
12. 如果系统推荐低脂但不喜欢的菜，你会怎么办？

### 风险问题

13. 你有过敏或忌口吗？
14. 你希望系统在什么情况下拒绝推荐？
15. 你是否愿意手动输入食材？
